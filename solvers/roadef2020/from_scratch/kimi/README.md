# ROADEF 2020 · Kimi-code

This is the from scratch implementation selected for the report.

Run from the repository root on Linux with a fresh output directory.

```sh
bash solvers/roadef2020/from_scratch/kimi/build.sh
python3 tools/run_instance.py --solver roadef2020/from_scratch/kimi --split train --instance C_02 --seed 1111 --seconds 180 --out /tmp/codeevo-example-roadef2020-from_scratch-kimi
```
