# PFSP · Kimi-code

This is the from scratch implementation selected for the report. Selected version: `v047`.

```sh
bash solvers/pfsp/from_scratch/kimi/build.sh
python3 tools/run_instance.py --solver pfsp/from_scratch/kimi --split train --instance VFR100_20_1 --seed 1111 --seconds 5 --out /tmp/codeevo-example-pfsp-from_scratch-kimi
```
