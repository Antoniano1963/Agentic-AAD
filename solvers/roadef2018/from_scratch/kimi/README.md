# ROADEF 2018 · Kimi-code

This is the from scratch implementation selected for the report.

Run from the repository root on Linux with a fresh output directory.

```sh
bash solvers/roadef2018/from_scratch/kimi/build.sh
python3 tools/run_instance.py --solver roadef2018/from_scratch/kimi --split train --instance B1 --seed 1111 --seconds 15 --out /tmp/codeevo-example-roadef2018-from_scratch-kimi
```
