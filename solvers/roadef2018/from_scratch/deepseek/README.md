# ROADEF 2018 · DeepSeek Harness

This is the from scratch implementation selected for the report.

```sh
python3 tools/run_instance.py --solver roadef2018/from_scratch/deepseek --split train --instance B1 --seed 1111 --seconds 15 --out /tmp/codeevo-example-roadef2018-from_scratch-deepseek
```
